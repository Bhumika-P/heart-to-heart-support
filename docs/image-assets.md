# Image asset provenance

Original portrait, logo files, favicon, and design reference were supplied in `Z:\Mom Website`. `assets/img/concept-details.png` preserves the supplied reference and supplies session/resource thumbnails through CSS positioning; it is not the rendered website.

Two supporting scenery assets were created with the built-in image-generation tool using `design1.png` as the reference:

- `assets/img/scenery/mountain-sunrise.png`: Reconstruct only the hero photograph: layered misty mountains, warm peach sunrise, sun in the right third, evergreen forest, distant lake, rocky path in the right foreground, quiet pale left side, 3:1 photograph, no text or website elements.
- `assets/img/scenery/mountain-boardwalk.png`: Reconstruct only the overlook photograph: wooden boardwalk and rustic timber railing, pine trees, hazy mountain valley, cream peach sky, restrained warm colors, 3:2 photograph, no people, text, or interface elements.

These are close visual reconstructions, not exact originals extracted from a layered design file. All assets referenced by the site are stored inside this repository.
